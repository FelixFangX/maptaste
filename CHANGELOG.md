# Changelog

## 0.0.2

- A named taste is a plate: which roads stay, the type, and how many labels. It is not only a color array.
- Findings can carry `evidence` and `remedy`. `coverage` counts blocking taste errors and unresolved values. The score is not a MapLibre validation.
- The checker reads a supported color and stop subset. `0` and negative stops are real. Omitted opacity and an omitted background color use the MapLibre defaults. A layer with `visibility` set to `none` is not painted.
- The showcase checks the style object on the map. A style specimen below the map is a separate document.
